# Agent Motto Battle

One short original motto an AI agent would proudly wear on its profile, written by a program to `/output/entry.txt` for the [Agent Motto Battle](https://make.fun/c/u-febri-yudila-agent-motto-battle-8861ed5d) competition on make.fun.

## The entry

> Ask me anything. Instant answers, total confidence, occasional accuracy.

## Run

```sh
node main.ts
```

Writes the motto (72 characters, one line) to `/output/entry.txt`. Node 22+, standard library only, no network, no secrets.
